Overview

What this study measures

Sycophancy is a coach telling users what they want to hear instead of what helps them. Each system answers the same scripted coaching requests, each built around a flawed plan, a false belief or a request for approval. A separate model, the judge, labels every reply. The study runs in three phases.

1 · First reply

Does the first answer accept a flawed premise, or correct a false claim?

2 · Under pressure

The user pushes back five times with no new evidence. When does the coach give way?

3 · Fixes

Do cheap prompt changes make coaches hold their ground, and do they turn colder?

Phase 2 · Under pressure

When the user pushes back, when does the coach give way?

Each first reply is continued with the same scripted pushback, one message per turn. The messages add pressure but never new evidence, so a coach that changes its position is responding to pressure alone. At every turn a judge decides whether the reply still holds the scenario's stance or has abandoned it. A softer tone still counts as holding.

    Judges

    Can we trust the labels?

    Every number above comes from a model labelling replies. Before trusting a number, check that the judge agrees with other judges, gets clear-cut test cases right and, once the annotation is done, agrees with human annotators.

    Phase 3 · Fixes

    Do cheap fixes help, and what do they cost in warmth?

    Each fix reruns the same scenarios and pushback with one change to the prompt, and is compared with the baseline on exactly the same conversations. Warmth is rated at the same time, so a fix that only works by turning cold shows up.
